Kate's Library 개인정보처리방침

시행일: 2026년 11월 3일

요약: Kate's Library는 사용자가 직접 등록한 책, 독서 기록, 노트, 저장 문장, 이미지/OCR 데이터, AI 대화와 백업 데이터를 앱 기능 제공을 위해 처리합니다. 광고 목적으로 개인정보를 판매하지 않습니다.

문의 및 삭제 요청 이메일: superjump.kr@gmail.com

1. 적용 범위

이 개인정보처리방침은 모바일 애플리케이션 Kate's Library(Android 패키지명: com.mybooklibrary.app, iOS 번들 ID: kr.superjump.mybooklibrary)에서 처리되는 개인정보와 사용자 데이터에 적용됩니다.

2. 처리하는 데이터

분류 예시 처리 목적

3. 데이터 처리 위치와 제3자 서비스

Kate's Library는 앱 기능 제공을 위해 다음 서비스 제공업체를 사용할 수 있습니다.

  • Firebase / Google Cloud: 로그인, 데이터 저장, Firestore, Storage, Cloud Functions, 백업, 구독/사용량 관리
  • Google Play: 앱 배포, 인앱 결제 또는 구독 처리
  • Apple: Apple 로 로그인, App Store 앱 배포, 인앱 결제 또는 구독 처리
  • Google Books, Kakao Book API, Open Library: 사용자가 요청한 책 검색 및 메타데이터 조회
  • OpenAI API 및 Google Gemini API: AI 대화, OCR/텍스트 처리, 목차 추출, 리서치, 요약 및 답변 생성

AI 기능을 사용할 때 사용자의 질문과 앱 내 책 관련 컨텍스트가 외부 AI API로 전송될 수 있습니다. 민감한 개인정보를 AI 질문이나 노트에 직접 입력하지 않는 것을 권장합니다.

4. 데이터 공유

Kate's Library는 사용자의 개인정보를 광고 목적으로 판매하지 않습니다. 다만 앱 기능 제공, 보안, 결제, 백업, AI 처리, 법적 의무 준수를 위해 위에 명시된 서비스 제공업체와 필요한 범위의 데이터가 처리될 수 있습니다.

5. 보관 기간

  • 계정 및 클라우드 데이터는 사용자가 계정을 유지하는 동안 보관됩니다.
  • 사용자가 직접 삭제한 책, 노트, 저장 문장, 백업 데이터는 앱 기능과 백업 상태에 따라 삭제 또는 복원 대상에서 제외됩니다.
  • 계정 삭제 요청이 접수되면 합리적으로 필요한 기간 내에 계정과 관련 데이터를 삭제합니다. 단, 같은 영수증으로 중복 지급되는 것을 막기 위한 구매 확인용 식별자(개인을 식별하는 정보는 포함하지 않음), 이용 제재 기록, 비용 정산용 사용 기록(90일 후 자동 삭제)은 법적 의무, 보안, 결제 분쟁, 부정 사용 방지를 위해 계정 삭제 뒤에도 제한된 기간 보관될 수 있습니다.

6. 사용자의 선택과 권리

  • 사용자는 앱 안에서 책, 노트, 저장 문장, 백업 데이터를 삭제할 수 있습니다.
  • 앱 안에서 계정 삭제: 설정 > 계정 삭제에서 직접 계정을 삭제할 수 있습니다. 삭제하면 게시글·댓글·팔로우·좋아요·신고, 받은 알림, 클라우드 백업, 프로필 사진, 사용자 정보와 로그인 계정이 삭제되며 되돌릴 수 없습니다. 보안을 위해 삭제 직전에 다시 로그인해야 하고, Apple 로 로그인한 계정은 Apple 과의 연결 해제도 시도합니다.
  • 구독은 앱 삭제나 계정 삭제로 해지되지 않으므로 App Store 또는 Google Play 에서 직접 해지해야 합니다.
  • 앱을 열 수 없는 경우 등 필요하면 계정 및 관련 데이터 삭제를 요청할 수 있습니다.
  • 삭제 요청은 계정 및 데이터 삭제 요청 페이지 또는 문의 이메일을 통해 보낼 수 있습니다.

7. 보안

Kate's Library는 HTTPS, Firebase Authentication, Firebase Security Rules 등 서비스 제공업체가 제공하는 보안 기능을 사용해 데이터를 보호합니다. 다만 인터넷을 통한 데이터 전송과 저장이 완전히 무위험일 수는 없습니다.

8. 아동 개인정보

Kate's Library는 아동을 주된 대상으로 설계된 앱이 아닙니다. 만 13세 미만 또는 거주 국가에서 정한 디지털 동의 연령 미만 사용자는 보호자의 동의와 지도하에 앱을 사용해야 합니다.

9. 국외 이전

Firebase, Google Cloud, Apple, OpenAI, Google Gemini 등 글로벌 서비스 제공업체를 사용하는 과정에서 데이터가 사용자의 국가 외 지역에서 처리될 수 있습니다.

10. 방침 변경

앱 기능, 사용 서비스, 법적 요구사항이 바뀌면 이 개인정보처리방침을 업데이트할 수 있습니다. 중요한 변경이 있는 경우 앱 또는 스토어 등록정보를 통해 고지할 수 있습니다.
