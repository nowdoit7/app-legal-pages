# App Legal Pages

Reusable static legal pages for apps published by this developer account.

## Current pages

- Kate's Library privacy policy: `apps/kates-library/privacy-policy/`
- Kate's Library data deletion request: `apps/kates-library/data-deletion/`

## Publishing with GitHub Pages

Recommended repository name:

```text
app-legal-pages
```

Recommended Play Console URLs after GitHub Pages is enabled:

```text
https://nowdoit7.github.io/app-legal-pages/apps/kates-library/privacy-policy/
https://nowdoit7.github.io/app-legal-pages/apps/kates-library/data-deletion/
```

## Before publishing

Support email currently used for Kate's Library:

```text
superjump.kr@gmail.com
```

## Reuse for another app

1. Copy `apps/kates-library/` to `apps/{new-app-slug}/`.
2. Replace app name, package name, service providers, collected data, and contact email.
3. Keep a separate privacy policy URL per app so Play Console declarations stay accurate.
